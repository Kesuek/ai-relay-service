# T-077: node-cli --json Output

**Goal:** Add `--json` global option to node-cli. When set, all subcommands output raw server JSON instead of formatted text. Also add a `@with_client` decorator to eliminate the 4-line boilerplate (`_setup_logging` + `load_meta` + `_effective_config` + `RelayClient`) from every `_cmd_*` function.

## Step 1: Add `--json` global option + `@with_client` decorator

**Changes in `nodes/common/node_cli.py`:**

1. Add `--json` to the root parser (after `--log-level`):
```python
parser.add_argument(
    "--json",
    action="store_true",
    help="Output raw JSON instead of formatted text (for scripting).",
)
```

2. Add `@with_client` decorator before the `_cmd_*` functions:
```python
import functools

def with_client(func):
    """Decorator: injects (client, args) into _cmd_* functions.
    
    Handles _setup_logging, load_meta, _effective_config, RelayClient
    so every command doesn't repeat the same 4 lines.
    """
    @functools.wraps(func)
    def wrapper(args):
        _setup_logging(args.log_level)
        meta = load_meta()
        cfg = _effective_config()
        client = RelayClient(meta, cfg)
        return func(client, args)
    return wrapper
```

## Step 2: Apply `@with_client` to all `_cmd_*` functions

Remove the 4 boilerplate lines from each function and add the decorator.

**Before:**
```python
def _cmd_heartbeat(args):
    _setup_logging(args.log_level)
    meta = load_meta()
    cfg = _effective_config()
    client = RelayClient(meta, cfg)
    caps = load_active_profile()
    hb = client.heartbeat(caps, {})
    print(json.dumps(hb, indent=2, default=str))
    return 0
```

**After:**
```python
@with_client
def _cmd_heartbeat(client, args):
    caps = load_active_profile()
    hb = client.heartbeat(caps, {})
    if args.json:
        print(json.dumps(hb, default=str))
        return 0
    print(json.dumps(hb, indent=2, default=str))
    return 0
```
