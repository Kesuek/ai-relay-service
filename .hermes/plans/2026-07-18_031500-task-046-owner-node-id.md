### Task 2: Client — `node-cli task submit` mit `--owner`-Flag

**Objective:** `node-cli task submit --owner <node_id>` setzt `owner_node_id` im Task.

**Files:**
- Modify: `nodes/common/node_cli.py` (Parser + `_cmd_task_submit` + `RelayClient.submit_simple_task`)

**Step 1: `RelayClient.submit_simple_task()` erweitern**

Füge Parameter `owner_node_id: str | None = None` hinzu und sende ihn im Body mit:

```python
def submit_simple_task(
    self,
    capability: str,
    payload: dict[str, Any],
    *,
    name: str = "",
    priority: int = 0,
    owner_node_id: str | None = None,
) -> dict[str, Any]:
    body = {
        "capability": capability,
        "payload": payload,
        "name": name,
        "priority": priority,
    }
    if owner_node_id:
        body["owner_node_id"] = owner_node_id
    r = self._post_with_retry("/relay/v2/scheduler/task-simple", body)
    r.raise_for_status()
    return r.json()
```

**Step 2: Parser erweitern**

Füge `--owner`-Argument zum `p_submit`-Parser hinzu (nach `--priority`):

```python
p_submit.add_argument(
    "--owner",
    default=None,
    help="Node ID that must claim this task (owner_node_id).",

```

**Step 3: `_cmd_task_submit` anpassen**

Übergib `owner_node_id=args.owner` an `client.submit_simple_task()`.
