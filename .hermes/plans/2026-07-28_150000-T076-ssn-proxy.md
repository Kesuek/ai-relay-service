# T-076: SSN Proxy — HTMX-Server für Capability-Pages

**Goal:** SSN-Proxy (localhost:8790) servt Capability-Pages als HTML-Templates mit HTMX. Der SSN-Daemon heartbeatet die Proxy-Endpoints als Dynamic Routes (T-075). Browser spricht Relay an → Relay leitet an SSN-Proxy weiter → SSN-Proxy macht Relay-Calls mit SSN-Node-Token.

**Architecture:**
- `nodes/common/ssn_proxy.py` — FastAPI-App auf localhost:8790
- 3 Endpoints: task-submit, tasks/{id}, storage/{id} — alle mit SSN-Node-Token
- HTML-Templates mit HTMX (kein client-seitiges JS)
- SSN-Daemon heartbeatet Routes via `ssn.yaml`-Erweiterung
- `systemd/ai-relay-ssn-proxy.service`

---

## Step 1: ssn.yaml um routes erweitern

**File:** `~/.relay/capabilities.d/ssn.yaml` (auf dem CT)

Add routes block to the ssn.capability-pages capability.

## Step 2: ssn_proxy.py — HTMX-Server

**File:** `nodes/common/ssn_proxy.py`

FastAPI-App with:
- `POST /api/task-submit` — relay POST /relay/v2/scheduler/task-simple
- `GET /api/tasks/{id}` — relay GET /relay/v2/scheduler/tasks/{id}
- `GET /api/storage/{id}` — relay GET /relay/v2/storage/files/{id}
- `GET /mflux` — mflux HTML page
- `POST /mflux/generate` — submit task, poll, return result HTML
- `GET /mflux/bilder/{id}` — serve cached image
