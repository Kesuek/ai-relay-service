# T-074: node-daemon — SSE-betriebene Referenz-Implementierung

## Ziel
Ein neuer `node-daemon` (separate Datei `nodes/common/node_daemon.py`), der
statt Polling einen SSE-Client nutzt. `node-cli daemon` bleibt unverändert.

## Architektur

```
node-daemon
├── Thread 1: Heartbeat (wie node-cli daemon, alle 30s)
├── Thread 2: SSE-Client (Event-Stream, reconnect bei Abbruch)
└── Thread 3: Claim/Execute/Complete (wird von SSE-Events getriggert)
```

## Datei: nodes/common/node_daemon.py

### Klasse: SseDaemon

```python
class SseDaemon:
    def __init__(self, client: RelayClient, cfg: dict):
        self.client = client
        self.cfg = cfg
        self._stop_event = threading.Event()
        self._sse_thread: threading.Thread | None = None
        self._hb_thread: threading.Thread | None = None
        self._in_flight: dict[str, int] = {}
        self._lock = threading.Lock()
        self._started_at = datetime.now(timezone.utc)
```

### Methoden

1. **`run()`** — Startet Heartbeat-Thread + SSE-Thread, wartet auf Stop
2. **`_heartbeat_loop()`** — Identisch zu node-cli daemon (alle 30s)
3. **`_sse_loop()`** — SSE-Client mit Reconnect:
   - Verbindet zu `GET /relay/v2/events/stream?node=<id>&types=stage_claimed,task_created`
   - Auth via Node-Token (Bearer)
   - Bei Verbindungsabbruch: 5s warten, reconnect
   - Bei `stage_claimed`-Event: Capability prüfen, claimen, ausführen
   - Bei `task_created`-Event: Prüfen ob Capability passt, claimen
4. **`_handle_stage_claimed(event)`** — Prüft ob die Capability zu diesem Node passt, claimt die Stage, führt sie aus
5. **`_run_stage(cap, stage)`** — Identisch zu node-cli daemon (run_handler + complete)
6. **`stop()`** — Setzt Stop-Event, beendet Threads

### SSE-Client (httpx streaming)

```python
async with httpx.AsyncClient() as http:
    async with http.stream(
        "GET",
        f"{base}/relay/v2/events/stream?node={node_id}&types=stage_claimed,task_created",
        headers={"Authorization": f"Bearer {token}"},
        timeout=None,
    ) as resp:
        async for line in resp.aiter_lines():
            if line.startswith("data: "):
                event = json.loads(line[6:])
                self._on_event(event)
```

Da der Daemon synchron ist (threading), wird der SSE-Client in einem
eigenen Thread mit `asyncio.run()` gestartet.

### CLI-Interface

```python
def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="node-daemon")
    parser.add_argument("--log-level", ...)
    parser.add_argument("--foreground", action="store_true", help="Run in foreground")
    return parser

def main():
    args = build_parser().parse_args()
    _setup_logging(args.log_level)
    meta = load_meta()
    cfg = _effective_config()
    client = RelayClient(meta, cfg)
    daemon = SseDaemon(client, cfg)
    daemon.run()
```

### systemd-Unit

`ai-relay-node-daemon.service` — analog zu `ai-relay-node-cli.service`,
aber mit `ExecStart=node-daemon` statt `node-cli daemon foreground`.
